# Aurevia Grand Hotel - Wedding Venue Reservation System

A Full Stack Web Application developed for the **Rapid Application Development (RAD - ITS2020)** module at **IJSE**.

##  Technologies Used
- **Frontend:** React + TypeScript, TailwindCSS, Redux Toolkit
- **Backend:** Node.js + Express.js + TypeScript
- **Database:** MongoDB
- **Security:** JWT Authentication, bcryptjs
- **Advanced Features:** PDF Slip Generation, AI Wedding Assistant
